### 步骤 5 — Serilog 异步刷盘 + 启动期不落盘

5.1 当前 `AppLogService.Initialize` 是同步 `WriteTo.File`，每次 Information 都可能触发磁盘 IO。
**禁止**新增 `Serilog.Sinks.Async` NuGet 包（违反 AGENTS.md 第 4.2 节"减少依赖"），改为以下两条手法叠加：

```csharp
.WriteTo.File(
    Path.Combine(logDirectory, "MyTools.log"),
    rollingInterval: RollingInterval.Day,
    retainedFileCountLimit: 14,
    fileSizeLimitBytes: 5 * 1024 * 1024,
    rollOnFileSizeLimit: true,
    shared: false,
    buffered: true,
    flushToDiskInterval: TimeSpan.FromSeconds(2),
    encoding: System.Text.Encoding.UTF8)
```

5.3 `AppLogService.CloseAndFlush()` 已在 `App.OnExit` 调用，保留不变；`buffered: true` 配合 2 秒 `flushToDiskInterval`，崩溃时最多丢 2 秒日志，可接受（AGENTS 4.4 节未要求实时落盘）。

5.4 自测：启动后写入 `MyTools.log`，停留 5 秒后查看文件存在且有内容。否则回滚 `buffered` 设置。

```markdown

### 9.1 启动期黄金 500 ms 原则
- `App.OnStartup` 与 `MainWindow` 构造函数中**严禁**执行任何耗时 > 50 ms 的 IO、注册表查询、WMI 调用、`Assembly.GetEntryAssembly().Location` 之外的反射。

- 凡是"加载历史"、"扫描磁盘"、"查询硬件"、"读取注册表"、"枚举启动项"、"枚举已安装程序"等任务，必须通过 `Dispatcher.BeginInvoke(DispatcherPriority.ApplicationIdle, ...)` 延后；或在用户点击对应模块时按需加载。

### 9.2 ViewModel 构造约束
- `MainViewModel` 构造函数**禁止**直接 `new` 子 ViewModel（如 `ScheduleViewModel`、`SystemSettingsViewModel`），必须以懒加载属性形式暴露。

- 任何 `ObservableCollection<T>` 在构造时**禁止**预填充数据（保持空集合，数据从延迟加载方法填入）。

### 9.3 面板可见性约束
- `MainWindow.xaml` 中每个模块面板的**最外层** Grid 默认 `Visibility="Collapsed"`，仅 Home 默认 `Visible`。
- 切换可见性必须通过 `DataTrigger Binding=CurrentModule` 实现；**禁止**用 `Hidden`（不释放布局）。
- 单个面板 XAML 行数 > 800 行时，必须抽出到 `src\MyTools\Views\<Module>View.xaml` 作为 UserControl。

### 9.4 日志与磁盘 IO 约束
- Serilog `File` Sink 必须 `buffered: true` + `flushToDiskInterval` ≤ 2 秒，**禁止**同步刷盘。
- 启动期 `MyTools.startup.log` 的追加写入**必须**通过 `ApplicationIdle` 延后到主窗口可见之后，避免首屏写盘。

### 9.5 内存与 GC 约束
- `App.config` 的 `<runtime>` 节点必须保留 `<gcServer enabled="true"/>` 与 `<gcConcurrent enabled="true"/>`。
```

**错误（启动期同步触发 8 个异步任务）**：

```csharp
    SafeFireAndForget(LoadSystemInfoSnapshotAsync());
```

**正确**：
```csharp
public MainViewModel()
{
    // ... 280 行命令初始化保持不变 ...
    CurrentModule = "Home";
    ScheduleStartupBackgroundLoads();
}

private void ScheduleStartupBackgroundLoads()
{
    var dispatcher = System.Windows.Application.Current?.Dispatcher
                     ?? System.Windows.Threading.Dispatcher.CurrentDispatcher;
    dispatcher.BeginInvoke(
        System.Windows.Threading.DispatcherPriority.ApplicationIdle,
        new Action(() =>
        {
            SafeFireAndForget(LoadSystemInfoSnapshotAsync());
            SafeFireAndForget(LoadRecordingOutputFoldersAsync());
            LoadScreenshotHistory();
            SafeFireAndForget(LoadRecentVideoViewerPlaylistsAsync());
            SafeFireAndForget(LoadFavoriteVideoViewerPlaylistsAsync());
            SafeFireAndForget(LoadSqlConnectionHistoryAsync());
            SafeFireAndForget(LoadScreenshotSettingsAsync());
            SafeFireAndForget(LoadCodexProfilesAsync());
        }));
}
```
