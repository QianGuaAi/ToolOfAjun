# 全功能测试任务说明书

## 【角色定义】

你是一个专门负责全面测试 MyTools 桌面工具的测试助手，需要对程序的每一个功能模块进行实际操作，识别 bug 并修复。

## 【任务目标】

对 MyTools.exe 的全部功能模块进行实际使用测试，发现问题立即修复并更新文档，最终交付一个稳定可用的版本。

## 【执行步骤】

### 阶段一：测试前准备（由主 agent 执行）

1. 构建最新 Release 版本：
   ```
   dotnet build src\MyTools\MyTools.csproj -c Release
   ```
2. 复制到测试目录：`artifacts\installer\payload\MyTools.exe`
3. 编译安装程序（用于有需要时安装）：
   ```
   dotnet build src\MyTools.Installer\MyTools.Installer.csproj -c Release
   ```
4. 启动程序，确保无 XAML 解析错误、无启动崩溃
5. 确认无遗留进程：`Get-Process MyTools | Stop-Process -Force`

### 阶段二：逐模块功能测试（由多个 agent 并行执行）

#### Agent A：系统模块测试

按以下顺序测试系统模块，每个功能必须**实际点击操作**：

1. **当前网络** → 检查网卡列表是否显示、流量/延迟数据是否刷新
2. **启动管理** → 检查启动项列表是否加载、启用/禁用切换是否生效
3. **程序卸载** → 检查已安装程序列表是否显示、卸载按钮是否可用
4. **系统信息** → 检查 CPU/内存/磁盘信息是否加载
5. **性能测试** → 检查基准测试按钮是否可用、结果是否显示
6. **系统设置** → 检查各子项（备份恢复/桌面背景/Windows 调整）是否正常
7. **系统优化** → 检查各项优化功能是否可用

#### Agent B：工具模块测试

1. **多媒体** → 检查音频/视频播放是否正常、播放列表是否工作
2. **截图工具** → 检查截图热键是否响应、截图历史是否记录
3. **SQL 导出** → 检查数据库连接、查询执行、导出 Excel 是否成功
4. **FRP 穿透** → 连接服务器 `http://120.26.50.234/`（SSH key 在 `C:\Users\QianGua\.ssh`），**不要动服务器的 web 服务**，检查隧道建立是否成功
5. **Codex 配置** → 检查配置管理、Profiles 切换是否生效
6. **文件验证** → 检查哈希计算、校验功能是否正常

#### Agent C：日程模块测试

1. 打开日程模块
2. 检查排班日历是否正常显示
3. 测试排班冲突检测是否工作
4. 测试导出功能（Excel 导出）

### 阶段三：问题修复（由主 agent 执行）

1. 汇总各 agent 发现的问题
2. 按严重程度排序：高（闪退/数据丢失）→ 中（功能失效）→ 低（UI/体验）
3. 逐个修复
4. 每修复一个，重新构建并测试验证

### 阶段四：文档更新（由主 agent 执行）

1. 更新 `docs/功能说明.md` 中的模块状态
2. 更新 `docs/开发记录.txt`，记录本次测试及修复内容
3. 重新编译最终版本

- 每个模块的测试结果（通过/失败/待人工验证）

- 如果某个功能需要特定环境（如 SQL Server、MySQL 数据库），在无环境时标记为"环境依赖-待验证"
