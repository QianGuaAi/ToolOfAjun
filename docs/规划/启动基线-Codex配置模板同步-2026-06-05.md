# 启动基线说明 - Codex 配置模板同步

## 变更范围

- `MainViewModel` 构造函数新增 `ApplyCodexConfigTemplateToAllCommand` 命令实例化与属性绑定。
- 未新增启动期磁盘 IO、注册表查询、WMI 调用、后台批量任务或重型子 ViewModel 创建。
- 新增的 Codex 配置模板同步逻辑只在用户点击单条档案的“应用到所有”按钮后执行。

## 启动基线

- 本次未重新测量启动首帧、稳态私有工作集和单 exe 体积。

## 未测原因

- 当前环境 `PATH` 中没有 `dotnet`。
- 仓库根目录未包含说明中提到的 `.dotnet/` SDK。
- 仅找到 .NET Framework 4.x 旧版 `MSBuild.exe`，该工具不支持当前 `Microsoft.NET.Sdk.WindowsDesktop` SDK 风格项目，执行 `MSBuild.exe src\MyTools\MyTools.csproj /p:Configuration=Release` 会在项目文件第 1 行报 `MSB4041`。

## 风险判断

- 构造函数新增内容仅创建一个 `AsyncRelayParameterCommand` 对象，不触发磁盘、网络、注册表、WMI 或大对象反序列化。
- 预计不会影响启动期黄金 500 ms 原则。
