# 启动基线 - Codex 重启助手（2026-05-27）

## 修改范围
- `MainViewModel` 构造函数仅新增 `RestartCodexDesktopCommand` 命令对象创建。
- 未在构造函数中新增磁盘 IO、注册表查询、WMI 调用、进程枚举或后台批量任务。
- `CodexDesktopService` 的进程枚举与 AppID 解析只在用户点击"重启 Codex"或轮换成功后确认重启时执行。

## 启动性能说明
- 本次未做外部窗口句柄计时复测。
- 未测原因：改动路径不参与启动期重型逻辑，仅增加一个轻量命令对象，符合启动期允许操作范围。

## 风险边界
- "重启 Codex"先请求主窗口正常关闭，并等待 Codex App 相关进程退出。
- 如果仍有 `WindowsApps\OpenAI.Codex_*` 或 `%LOCALAPPDATA%\OpenAI\Codex\` 下的遗留 Codex 进程未退出，工具会结束这些 Codex App 进程后再重新打开。
- 结束进程范围仅限 Codex App 安装目录和 Codex App 本地后端目录，不按进程名结束其他位置的 `codex.exe`。
- 如果结束后仍有 Codex App 进程未退出，工具停止重启流程并提示用户手动处理。
