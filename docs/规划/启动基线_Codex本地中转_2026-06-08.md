# 启动基线说明 - Codex 本地中转

## 变更范围

- `App.OnStartup` 新增 `--codex-local-relay` 后台模式分支；普通 UI 启动路径仅增加一次命令行参数判断，不增加磁盘 IO、网络请求或配置反序列化。
- `MainViewModel` 构造函数新增 `EnableCodexLocalRelayCommand` 与 `RestartCodexWithLocalRelayCommand` 命令对象创建；未新增重型子 ViewModel、同步 IO、网络请求或后台批量任务。

## 基线结论

- 本次未做首帧毫秒级实测：当前任务在编码环境中完成，未启动交互式窗口做冷启动计时。
- 代码审查结论：普通 UI 启动期未新增超过 50 ms 的同步 IO / 注册表 / WMI / 网络操作。
- Codex 本地中转的设置读取、后台 relay 启动和健康检查均发生在用户点击“启动本地中转”或 Codex 配置模块延迟加载后；远程 NewAPI 探测只由用户点击触发，不在 `App.OnStartup` / `MainWindow` 构造函数 / `MainViewModel` 构造函数中执行。
