# 启动基线说明 - Codex 停止使用本地中转

## 修改范围
- `MainViewModel` 构造函数新增 `DisableCodexLocalRelayCommand` 命令对象创建，并公开 `CanDisableCodexLocalRelay` 状态属性。
- `MainModulesView.xaml` 在 Codex 配置面板中新增“停止使用本地中转”按钮。

## 启动期影响
- 构造期新增内容仅为一个 `AsyncRelayCommand` 对象和属性引用，属于启动期允许的命令对象创建。
- 未在 `App.OnStartup`、`MainWindow` 构造函数或 `MainViewModel` 构造函数中新增磁盘 IO、网络请求、注册表查询、WMI 调用、大对象反序列化或批量后台任务。
- 停用本地中转时的设置读取、写入、relay 停止请求和状态刷新仅发生在用户点击“停止使用本地中转”之后。

## 未测说明
- 本次变更已计划通过 Release 编译验证覆盖类型、XAML 绑定和资源解析。
- GUI 首帧时间、稳态私有工作集和单 exe 体积需在最终打包或人工启动采样时记录；本次按钮和命令对象变更预计不引入启动首帧回退。
