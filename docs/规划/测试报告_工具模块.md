## 一、多媒体模块

### 1.1 功能描述

多媒体模块是一个集图片浏览、音视频播放、格式转换于一体的综合媒体管理工具。

**核心功能：**

| 功能 | 描述 |
|---|---|
| **磁盘浏览** | 左侧 TreeView 展示所有磁盘分区及子文件夹，支持懒加载（按需展开） |
| **图片浏览** | 支持 `.jpg` `.jpeg` `.png` `.bmp` `.gif` `.tiff` `.tif` `.webp` `.heic` 9 种格式；列表有缩略图（160px 降采样），预览有上下翻页按钮 |
| **音视频播放** | 预览区使用 WPF `MediaElement`；沉浸模式支持图片/音频/视频全屏展示；支持外部打开 |
| **截图复制** | 将当前查看的图片复制到剪贴板（`Bgr24` 格式，兼容经典画图和旧 Office） |
| **格式转换** | 图片支持 → `jpg` `png` `bmp` `gif` `tiff` `webp`；视频/音频支持 → `mp4` `mkv` `mov` `avi` `mp3` `wav` `aac` `flac`；需要 ffmpeg |
| **PDF 转换** | 图片转 PDF、PDF 转图片 |
| **右键菜单** | 格式转换 / 图片转 PDF / PDF 转图片 / 外部打开 |
| **虚拟化列表** | `MediaFileList` 使用 `VirtualizingPanel.VirtualizationMode="Recycling"`，大文件夹（100+ 图片）下有优化 |

**ffmpeg 查找路径（按优先级）：**
1. `NativeBinaries\ffmpeg\ffmpeg.exe`（随产物打包）
2. 程序根目录 `ffmpeg.exe`
3. `C:\ffmpeg\bin\ffmpeg.exe`
4. `C:\Program Files\ffmpeg\bin\ffmpeg.exe`
5. 系统 PATH 环境变量

## 二、截图工具模块

### 2.1 功能描述

| 功能 | 描述 |
|---|---|
| **全屏截图** | `ScreenshotService.CaptureFullScreen()` 使用 GDI `CopyFromScreen` 捕获整个虚拟屏幕（支持多显示器） |
| **鼠标光标绘制** | 截图时将当前可见光标绘制到位图上（`DrawCursorIfVisible`） |

| **热键** | `HotkeyService.ScreenshotHotkeyId = 9001`；默认热键由用户在设置页配置（存储在 `MyTools.settings.json`） |

## 三、SQL 导出模块

### 3.1 功能描述

| 功能 | 描述 |
|---|---|
| **数据库连接** | 支持 SQL Server / PostgreSQL / MySQL；仅支持 SQL 身份验证（无 Windows 身份验证） |
| **数据库列表** | SQL Server：`sys.databases` → 自动降级到 `sp_databases`（无足够权限时）；MySQL/PostgreSQL 各有独立 Provider |
| **数据表枚举** | `INFORMATION_SCHEMA.TABLES`（SQL Server）；Schema 名称通过白名单校验后用 `[` `]` 括起 |
| **导出为 Excel** | 自写 OpenXML `.xlsx` 生成器（`XlsxStreamWriter`），**无需安装 Office**；单 sheet 最多 `1,048,576` 行（Excel 上限）；超过自动分 Sheet |
| **导出为 CSV** | 支持导出 DataTable 查询结果为 CSV |
| **行数上限校验** | 导出前会 `SELECT COUNT_BIG(1)` 统计行数，超限提示用户 | **白名单校验** | Schema/表名来自程序加载的白名单，不允许拼接用户自定义 SQL |
| **密码保护** | SQL 密码使用 Windows DPAPI（当前用户）加密后存入本地配置 |
| **超时控制** | `ConnectTimeout = 10`；`CommandTimeout = 0`（不限制）；日志记录不包含密码 |

### 3.2 支持的数据库

| 数据库 | Provider | 连接字符串生成 | 数据库枚举 | 表枚举 |
|---|---|---|---|---|
| **SQL Server** | `SqlServerExportProvider` | `SqlConnectionStringBuilder` | `sys.databases` 或 `sp_databases` | `INFORMATION_SCHEMA.TABLES` |
| **PostgreSQL** | `PostgreSqlExportProvider` | Npgsql 连接字符串 | `pg_database` | `information_schema.tables` |
| **MySQL** | `MySqlExportProvider` | MySqlConnector 连接字符串 | `SHOW DATABASES` | `information_schema.tables` |

### 3.3 已知问题 / 潜在 Bug

| # | 严重度 | 问题描述 | 代码位置 | 备注 |
|---|---|---|---|---|
| Q1 | **高** | **`SELECT *` 导出问题**：使用 `SELECT * FROM schema.table` 导出，**列顺序依赖数据库定义顺序**，若表结构发生变更（新增列/删除列），两次导出文件的列顺序可能不一致，导致对比困难 | `SqlExportService.cs:188` | 建议在导出时明确指定列顺序，或在 UI 提示此风险 |
| Q2 | **中** | **`SELECT *` 安全性**：`SELECT *` 不符合白名单规范（白名单校验仅针对 Schema 和表名），虽然有白名单校验，但列级内容完全取决于数据库当前 schema，若目标表被注入恶意列名（特殊 XML 字符），`SanitizeText` 可能无法正确处理 | `SqlExportService.cs:951-968` | 需验证极端情况 |
| Q3 | **中** | **Excel 格式的单元格类型有限**：自写 OpenXML 生成器仅支持布尔、数字、日期、GUID、Base64 二进制和文本（inline string）；不支持富文本、公式、URL 链接等；若源数据包含 `byte[]` 则输出 Base64 字符串而非数值 | `SqlExportService.cs:754-816` | |
| Q4 | **低** | **性能**：对于超大表（千万行），`XlsxStreamWriter` 使用 `XmlWriter` 顺序写入，无批量 flush 优化；内存压力中等 | `SqlExportService.cs:606-752` | |
| Q5 | **低** | **CSV 导出无编码声明**：CSV 文件使用 UTF-8 无 BOM 写入（`new UTF8Encoding(false)`），但 Excel 打开时若无 BOM 可能以系统默认编码（GBK）打开，导致中文乱码 | `SqlExportService.cs:336` | 建议添加 UTF-8 BOM 或让用户选择编码 |
| Q6 | **低** | **`GetTableRowCountAsync` 在大表上可能很慢**：`SELECT COUNT_BIG(1)` 在大表上可能需要很长时间（SQL Server 需要扫描） | `SqlExportService.cs:147-162` | 建议添加超时或给用户取消选项 |

- [ ] **大表导出（>100 万行）**：找一个超过 104 万行的表，测试自动分 Sheet 功能

## 四、FRP 穿透模块

### 4.1 功能描述

| 功能 | 描述 |
|---|---|
| **FRP 隧道管理** | 通过 `frpc.exe` 客户端连接 frps 服务器（默认 `120.26.50.234:7000`），建立 TCP 隧道 |
| **服务器预设** | `FrpServerPresetCatalog`：内置"阿里云主服务器"（`120.26.50.234:7000`） |
| **端口预设** | `FrpPortPresetCatalog`：10 种常用预设（RDP/SSH/MySQL/PostgreSQL/Redis 等） |
| **frpc 提取** | `EnsureFrpcExtractedAsync`：从嵌入资源（`.frpc.exe.gz` 或 `.frpc.exe`）解压到 `%TEMP%\MyTools\frpc.exe` |
| **配置持久化** | 配置保存到 `MyTools.frpconfig.json`；规则保存到 `MyTools.frprules.json` |
| **Token 加密** | Token 使用 Windows DPAPI 加密后存储 |
| **运行状态检测** | 通过检测 frpc stdout/stderr 中的 `login to server success` / `start proxy success` / `proxy added` 等关键字判断连接状态 |

### 4.2 服务器配置

> **默认服务器：`http://120.26.50.234/`（仅 FRP 用途，不要修改 web 相关配置）**

```ini
# frps.ini（服务器端）
[common]
bind_port = 7000
token = <用户自定义强密码>
```

```ini
# frpc.ini（客户端生成）
[common]
server_addr = 120.26.50.234
server_port = 7000
token = <DPAPI加密存储>
```

## 六、文件哈希验证模块

### 6.1 功能描述

| 功能 | 描述 |
|---|---|
| **单遍扫描** | 一次文件读取同时计算 MD5 / SHA-1 / SHA-256 / CRC32（通过 `TransformBlock` 并行喂入三个哈希算法） |
| **进度报告** | 每扫描 16 MB 报告一次进度（`已扫描 XX%`） |
| **预期值比对** | 用户可输入预期哈希值和类型，系统比对后显示"匹配"或"不匹配" |
| **取消支持** | 通过 `CancellationToken` 支持取消正在进行的哈希计算 |

### 6.2 支持的哈希算法

| 算法 | 输出格式 | 代码实现 |
|---|---|---|
| **MD5** | 32 位十六进制大写 | `MD5CryptoServiceProvider` |
| **SHA-1** | 40 位十六进制大写 | `SHA1CryptoServiceProvider` |
| **SHA-256** | 64 位十六进制大写 | `SHA256CryptoServiceProvider` |

### 6.3 已知问题 / 潜在 Bug

| # | 严重度 | 问题描述 | 代码位置 | 备注 |
|---|---|---|---|---|
| H1 | **低** | **MD5/SHA1 已不建议用于安全场景**：代码同时计算并展示 SHA-1，但 SHA-1 已被发现碰撞攻击，不应作为安全哈希使用；建议在 UI 上增加"仅用于校验，不用于安全场景"的提示 | `FileHashService.cs` | |
