# 菜单式界面改造任务说明书

## 【角色定义】

你是一个专门负责 `.NET Framework 4.8` + WPF + MVVM 桌面工具窗口框架改造的助手。你需要在 `MyTools` 项目中，把当前 `MainWindow.xaml` 的左侧导航栏改造为顶部菜单栏，并保持 `MetroWindow`、MaterialDesign 主题、系统托盘、现有 ViewModel 命令、现有业务服务和 Win7/10/11 兼容性不被破坏。

你必须先按本说明书核对真实代码，再动手修改。不得只根据旧规划、行号猜测或自己的 UI 习惯改造。

## 【任务目标】

交付一个可编译、可启动的菜单式主窗口：窗口从上到下为 `MetroWindow` 标题栏、顶部菜单栏、主操作区、底部状态栏。左侧 `176 px` 导航栏必须移除；顶部菜单必须复用当前 `MainViewModel` 已存在的导航命令；退出菜单必须复用当前 `ExitCommand`，不能绕过项目已有的托盘退出流程。

本任务优先完成菜单式布局本身。启动性能优化只做“不引入新回退”的基线维护；不要把大规模启动加速与菜单改造强行绑在同一次实现里，除非用户另行确认。

}
