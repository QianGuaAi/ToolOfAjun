## 一、日程（排班）模块

### 1.1 功能描述

日程模块是一个**医护人员排班管理系统**，支持按月份/版本管理排班表，具备自动排班生成、冲突检测、Excel导出等核心功能。

#### 核心功能清单

| 功能 | 实现状态 | 说明 |
|------|----------|------|
| 排班版本管理（新建/加载/保存/另存/删除） | ✅ 已实现 | 按 `YYYY-MM/版本名.json` 存储在 `%LOCALAPPDATA%\MyTools\Schedules\` |
| 人员管理（添加/删除/改名） | ✅ 已实现 | 支持单人多人和批量导入（CSV/TXT） |
| 班次编辑（手动设置白/夜/休等） | ✅ 已实现 | 9种班次代码；支持"小1"快捷操作 |
| 自动生成休息日 | ✅ 已实现 | `ShiftAutoOptimizer` 实现5级优先级算法 |
| 冲突检测与定位 | ✅ 已实现 | 硬约束（红色）+ 软警告（黄色）分级显示 |
| 整月班次复制 | ✅ 已实现 | 源人员→目标人员一键复制 |
| Excel导出 | ✅ 已实现 | 自写 OOXML，无需 Office；含样式、冻结窗格 |
| 节假日支持 | ✅ 已实现 | 内置2026广西节假日 + 用户 holidays.json 自定义 |
| 缩放与滚动 | ✅ 已实现 | 支持表格缩放（50%-200%）和滚动 |

#### 班次代码体系

| 代码 | 含义 | Excel显示 | 颜色 |
|------|------|------------|------|
| 白 | 白班 | 白 | 白底黑字 |
| 卡 | 卡班 | 卡 | 粉底黑字 |
| 副 | 副小 | 副 | 深红底白字 |
| 感 | 感染科 | 感 | 浅红底黑字 |
| 大 | 夜班 | 夜 | 深灰底白字 |
| 小 | 小夜 | 小 | 中灰底白字 |
| 休 | 休息 | 休 | 米黄底黑字 |
| 公 | 公休 | 公 | 绿底黑字 |
| 午 | 下午休 | 午 | 淡黄底黑字 |

### 1.2 数据存储

- **路径**：`%LOCALAPPDATA%\MyTools\Schedules\{YYYY-MM}\{版本名}.json`
- **节假日配置**：`%LOCALAPPDATA%\MyTools\holidays.json`（可选，覆盖内置节假日）
- **JSON结构**：
  - `Year/Month/VersionName`：版本标识
  - `DailyRestQuotas`：每日总休息人数硬性配额（0.5精度）
  - `Employees`：人员数组，每人含 `Name` 和每日 `Cells`
  - `GeneratedAt`：自动生成时间戳（非空时才允许导出Excel）

### 1.3 已知问题与潜在Bug

#### 🔴 高优先级

1. **`BuildPreservedCells` 返回空列表**
   - **位置**：`ScheduleViewModel.cs` 第 1145-1148 行
   - **问题**：方法声明接收 `IReadOnlyCollection<(int emp, int day)>` 参数，但实际返回空集合
   - **影响**：自动优化无法保护用户手动设置的单元格（理论上应保留，但目前空实现）
   - **建议**：检查是否有意为之；如需保留手动格，应返回实际的手动格坐标

2. **`ApplySmallNight1` 缺少越界保护**
   - **位置**：`ScheduleViewModel.cs` 第 1012-1026 行
   - **问题**：设置 dayIdx+3 时未检查是否超出当月天数
   - **影响**：月份末尾调用可能导致索引越界（虽然 `SetManualCell` 有边界检查，但参数越界时静默忽略）

#### 🟡 中优先级

3. **节假日 fallback 仅支持 2026 年**
   - **位置**：`HolidayService.cs` 第 21-34 行
   - **问题**：`BuiltinHolidays` 硬编码了 2026 年，2027+ 用户需自行配置 holidays.json
   - **建议**：在 UI 或日志中提示用户节假日配置状态

4. **`ScheduleExcelExporter` 节假日列"白班"显示为空**
   - **位置**：`ScheduleExcelExporter.cs` 第 218-219 行
   - **问题**：节假日列的空白单元格写入空字符串而非"白"字
   - **设计决策**：可能是预期行为（节假日列不显示班次），但可能导致理解混淆
   - **建议**：明确文档说明或添加注释

5. **自动优化可能在边界条件下产生不可预期的均衡交换**
   - **位置**：`ShiftAutoOptimizer.cs` 第 401-455 行（BalanceRestPass）
   - **问题**：两轮均衡交换可能导致最终结果与用户手动设置存在微妙差异
   - **建议**：在连续点击"设置休息日"时记录随机种子，显示差异对比

#### 🟢 低优先级

6. **`CopyPreviousMonthEmployees` 仅复制人员姓名**
   - **问题**：不复制人员顺序、班次偏好等个性化数据
   - **建议**：可考虑增加可选的"复制班次模板"功能

7. **大量人员时的性能**
   - **潜在问题**：2000人 × 31天 = 62,000单元格，UI渲染可能较慢
   - **建议**：代码中有注释提到"可视区域渲染"，需验证实际实现

## 二、系统设置模块

系统设置模块包含三个子模块：**备份恢复**、**桌面背景**、**Windows调整**。

### 2.1 备份恢复（Backup & Restore）

#### 功能描述

支持程序数据的完整备份与恢复，包括：
- **设置与历史**：程序配置（`MyTools.settings.json`）、SQL连接历史（`MyTools.sqlhistory.json`）
- **排班本地数据**：所有排班版本 JSON 文件
- **Codex 配置**：账号档案（`config.toml`、`auth.json`）
- **FFmpeg**：原生依赖（`NativeBinaries/`）

#### 备份结构

```
MyToolsBackup_yyyyMMdd_HHmmss/
├── manifest.json          # 备份清单（含来源机器/用户/时间戳）
├── App/
│   ├── MyTools.settings.json
│   ├── MyTools.sqlhistory.json
│   └── NativeBinaries/...
├── LocalAppData/MyTools/
│   └── Schedules/...
└── Codex/
    ├── config.toml
    └── auth.json
```

#### 关键特性

- **DPAPI 加密保护**：敏感数据使用 Windows DPAPI 当前用户范围加密
- **跨用户提示**：检测到备份来自不同用户时，提示 DPAPI 数据无法解密
- **预检机制**：支持预览导出/导入内容，避免误操作
- **完整性校验**：支持验证备份包的文件完整性和哈希匹配

#### 已知问题

| # | 问题 | 位置 | 影响 |
|---|------|------|------|
| 1 | `ExportAsync` 调用时 `BuildBackupSections()` 可能返回 `None` 但未拦截 | `SystemSettingsViewModel.cs` 第 183 行 | 空备份 |
| 2 | `ImportAsync` 的 `HadDpapiData` 判断仅检查文件名，未检查文件内容 | `SystemBackupService.cs` 第 285-289 行 | 跨用户恢复时可能静默失败 |

### 2.2 桌面背景（Wallpaper）

#### 功能描述

- **图库管理**：程序目录下 `Wallpapers/` 文件夹，支持导入/删除/刷新
- **壁纸设置**：Win7/8/10/11 通用 `SystemParametersInfo` API
- **显示方式**：填充/适应/拉伸/平铺/居中 5种
- **快捷操作**：保存当前桌面到图库、在看图模块浏览

#### 实现细节

- 使用 `SPI_SETDESKWALLPAPER` + 注册表 `WallpaperStyle`/`TileWallpaper`
- 读取当前壁纸：SPI_GETDESKWALLPAPER（优先级）→ 注册表 → TranscodedWallpaper缓存

#### 已知问题

| # | 问题 | 位置 | 影响 |
|---|------|------|------|
| 1 | `GetCurrentWallpaperPath` 在某些 Win10/11 系统可能返回缓存路径 | `WallpaperService.cs` 第 87-126 行 | 读取到旧的转码壁纸 |
| 2 | GIF 格式在某些系统上可能无法正确设为壁纸 | `WallpaperService.cs` | 仅支持 JPG/PNG/BMP |

### 2.3 Windows 调整（Windows Tweaks）

#### 功能描述

通过注册表调整 Windows 系统外观和行为，无需管理员权限。

| 调整项 | 注册表键 | 需要重启Explorer | 最低系统要求 |
|--------|----------|------------------|--------------|
| 时钟显示秒 | `HKCU\...\Advanced\ShowSecondsInSystemClock` | ✅ | Win11 22H2+ |
| 显示所有托盘图标 | `HKCU\...\Explorer\EnableAutoTray` + `NotifyIconSettings` | ✅ | Win10/11 |
| 任务栏按钮合并 | `HKCU\...\Advanced\TaskbarGlomLevel` | ✅ | Win10/11 |
| 右键完整菜单 | `HKCU\...\ClassicContextMenu` | ✅ | Win11 |
| 桌面图标（计算机/回收站/控制面板/用户文件/网络） | `HKCU\...\HideDesktopIcons` | ❌ | Win7+ |

#### 已知问题

| # | 问题 | 位置 | 影响 |
|---|------|------|------|
| 1 | Win10 系统上"显示所有托盘图标"逻辑较复杂，可能与 Win11 行为不一致 | `WindowsTweaksService.cs` 第 56-65 行 | Win10 用户体验可能不佳 |
| 2 | `RestartExplorer` 使用 `CloseMainWindow()` 后 `WaitForExit(1200ms)` 可能在慢系统上超时 | `WindowsTweaksService.cs` 第 140-186 行 | Explorer 未完全重启 |

## 三、系统优化模块

### 3.1 功能描述

系统优化模块提供一键自动优化功能，包含 10 个优化步骤：

| # | 步骤 | 权限要求 | 说明 |
|---|------|----------|------|
| 1 | 清空用户 Temp（24小时前） | 普通 | 自动删除过期临时文件 |
| 2 | 清空 Windows Temp（7天前） | **管理员(UAC)** | PowerShell 脚本执行 |
| 3 | 清理缩略图缓存 | 需用户授权重启Explorer | 删除 thumbcache_*.db |
| 4 | 刷新 DNS 缓存 | 普通 | `ipconfig /flushdns` |
| 5 | 重置字体缓存 | **管理员(UAC)** | 重启 FontCache 服务 |
| 6 | 清理 Windows 更新缓存 | **管理员(UAC)** | 停止 wuauserv 后删除 |
| 7 | 系统盘 TRIM/碎片整理 | **管理员(UAC)** | SSD 执行 TRIM，HDD 碎片整理 |
| 8 | 清空回收站 | 普通 | `SHEmptyRecycleBin` API |
| 9 | 清理事件日志（>500MB） | **管理员(UAC)** | 保留日志文件 |
| 10 | 压缩当前进程工作集 | 普通 | `EmptyWorkingSet` API |

## 四、系统托盘功能

### 4.1 功能描述

程序最小化或关闭时隐藏到系统托盘，提供右键菜单和双击恢复功能。

#### 托盘菜单结构

```
┌─────────────────────────┐
│ ▶ 显示窗口               │  ← RestoreCommand
│ ▶ 开启/关闭 开机自启     │  ← ToggleAutoStartCommand（动态文案）
│ ▶ 打开日志目录           │  ← OpenLogFolderCommand
├─────────────────────────┤
│ ✕ 退出程序               │  ← ExitCommand
└─────────────────────────┘
```

#### 实现细节

- **图标**：使用 `Resources/AppIcon.ico` 位图资源（避免 DrawingImage 导致 UriFormatException）
- **初始化时机**：窗口加载后 10 秒延迟初始化（`ScheduleDeferredStartupUi`）
- **双击行为**：执行 `RestoreCommand`，恢复主窗口并聚焦

### 4.2 已知问题

| # | 问题 | 位置 | 影响 |
|---|------|------|------|
| 1 | 托盘图标初始化有 10 秒延迟 | `MainWindow.xaml.cs` 第 124 行 | 快速最小化时可能看不到托盘图标 |
| 2 | 托盘菜单中"开机自启"文案动态切换 | `MainWindow.xaml.cs` 第 164-175 行 | DataTrigger 动态 Header 可能存在绑定延迟 |
| 3 | 托盘图标未在程序退出时显式销毁 | `MainWindow.xaml.cs` 第 28 行 | IDisposable 未完全实现 |

### 4.3 需要人工验证的关键点

| 验证项 | 验证方法 |
|--------|----------|
| 关闭主窗口 → 托盘图标是否显示 | 观察系统托盘区域 |
| 右键托盘图标 → 菜单是否正确显示 | 检查菜单项完整性 |
| 点击"显示窗口" → 主窗口是否恢复 | 验证窗口显示和聚焦 |
| 点击"退出程序" → 程序是否干净退出 | 检查进程列表，确认无残留 |
| 双击托盘图标 → 主窗口是否恢复 | 快捷操作测试 |
| 开机自启开关 → 切换 → 托盘菜单文案是否更新 | 验证动态文案 |
| 程序运行中托盘图标闪烁 | 某些操作可能触发托盘通知 |
