# 多媒体功能合并任务说明书

## 【角色定义】

你是一个专门负责 WPF 桌面工具模块重构、多媒体浏览界面设计、媒体播放与格式转换整合的助手。你需要在 `MyTools` 项目中，把现有"图片查看"、"音视频播放"、"格式转换"三个独立模块合并为一个新模块"多媒体"，并保持项目兼容 `.NET Framework 4.8` 与 Windows 7 SP1 及以上系统。改动必须遵守 `c:\exe\AGENTS.md` 的所有红线（启动 500 ms 黄金原则、禁止启动期 WMI、单 exe 分发、DPAPI、日志脱敏、面板 800 行强制拆分）。

## 【任务目标】

交付一个名为"多媒体"的统一模块：进入后程序内容区呈现资源管理器式三区布局（左上文件夹树、左下预览区、右侧文件列表），单击文件在预览区预览，双击文件进入沉浸式查看或播放，右键文件可打开格式转换弹窗设置参数，右上角"退出多媒体"按钮返回 `Home`。改动必须分 3 个阶段（A/B/C）落地，每阶段独立可回滚、独立可发布，避免一次性大改导致回归不可控。

## 【边界与限制】

1. 如果某个文件夹没有访问权限（`UnauthorizedAccessException`），则在右侧状态栏显示 `无权限访问该文件夹`，并保持程序可操作。

2. 如果某个媒体文件无法解码（`MediaElement.MediaFailed`），则预览区显示 `无法预览该文件`，并提供 `外部打开` 按钮。

3. 如果 `MediaElement` 无法播放某种格式但扩展名在支持清单内，则保留文件列表显示，并在预览失败时显示失败提示。

4. 如果 `MediaConvertService.FindFfmpeg()` 返回 `null`，则音视频区域必须显示 FFmpeg 缺失提示，并禁用 `确定`（仅当目标全部为音视频时）。

5. 如果右键目标不是图片、音频、视频文件，则右键菜单不显示 `格式转换` 项。
