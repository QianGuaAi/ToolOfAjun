# 启动基线说明 - 启动后菜单响应

日期：2026-06-24

## 变更范围

- `MainViewModel.ScheduleStartupBackgroundLoads()` 不再在启动后的 `ContextIdle` 队列中启动硬件传感器。
- `SystemInfo` 模块进入时才按需启动 `HardwareSensorService`，并把 `TryStart()` 与 `ReadAll()` 放到后台线程执行。
- `scripts/codex-eval.ps1 -Quick` 增加启动响应守卫，禁止把传感器启动重新放回启动后台加载队列，并断言传感器刷新不在 UI 线程同步执行。

## 启动影响判断

- `MainViewModel` 构造函数仍只创建集合、命令对象和计时器，不新增磁盘 IO、注册表枚举、WMI 或硬件探测。
- 启动后的空闲阶段只读取轻量 shell 状态，不再自动探测 LibreHardwareMonitor 传感器，避免窗口已经显示但菜单点击被硬件枚举排队阻塞。
- 系统信息页的传感器读数会在进入页面后异步回填；这会让首次打开系统信息时数据稍后出现，但不会按住菜单响应。

## 未实测原因

本次为了避免中断当前正在使用的安装版 local relay，没有覆盖安装并启动安装版做人工点击实测；以 Release build、`codex-eval -Quick` 静态门禁和启动路径代码审查作为验证。后续若允许替换安装版，可补做启动后 1-3 秒内点击顶部菜单的人工响应验证。
