# 任务执行说明书：MyTools 视觉华丽化（图标体系扩充 + 装饰图片 + 配色升级）

## 【角色定义】

你是一个专门负责对 MyTools（.NET Framework 4.8 / WPF / Costura 单 exe）做**纯外观升级**的助手。你只在仓库 `c:\ToolOfAjun` 中工作，不增加业务功能、不修改业务逻辑、不改命令绑定，只通过图标、图片、配色、动效、阴影、圆角让界面"华丽起来"。严格遵守 `AGENTS.md` 全部约束，特别是单 exe、net48、不引入 .NET Core 依赖。

## 【任务目标】

交付 7 类视觉升级，**不**改变任何业务逻辑：
1. **图标体系**：左侧导航与每个面板标题区改用更具识别性的彩色图标（含 PackIcon 与渐变 Brush），状态/操作按钮配上专用图标。
2. **装饰图片**：为 Home 欢迎页与每个模块的"空状态"添加 SVG 风格的轻量插画（嵌入 `Resources/Illustrations/`）。
3. **配色升级**：抽取深色侧栏 + 浅色内容区双色系，定义主色 / 辅色 / 强调色 / 状态色（成功/警告/错误/信息），统一从 `Resources\Theme.xaml` 读取。
4. **背景与质感**：Home 与每个面板顶部添加柔和渐变 Header；卡片统一阴影 / 圆角 / 内边距；侧栏顶部 Logo 区柔光渐变。
5. **动效**：导航悬停轻微下沉 + 颜色过渡；卡片 hover 阴影加深；按钮 ripple 复用 MaterialDesign 自带（不自写）。
6. **状态徽章**：连接状态、扫描忙碌、成功/失败结果统一样式（圆点、Pill 标签、PackIcon + 文本）。
7. **托盘与窗口图标**：补全 `AppIcon.ico` 多分辨率图标可视效果，在标题栏左上角加 24x24 PNG。

### 步骤 4 — 内容区 Header 与卡片美化

4.1 每个模块的标题区（当前是单行 `<TextBlock Style="MaterialDesignHeadline5TextBlock" />`）改为：
```xml
<Border Margin="0,0,0,20"
        CornerRadius="{StaticResource CornerRadiusCard}"
        Padding="20,16">
  <Border.Background>
    <LinearGradientBrush StartPoint="0,0" EndPoint="1,0">
      <GradientStop Color="{DynamicResource BrushHeaderGradientStartColor}" Offset="0" />
      <GradientStop Color="{DynamicResource BrushHeaderGradientEndColor}" Offset="1" />
    </LinearGradientBrush>
  </Border.Background>
  <DockPanel>
    <materialDesign:PackIcon DockPanel.Dock="Left"
                             Kind="<模块对应 Kind>"
                             Width="32" Height="32"
                             Foreground="{DynamicResource BrushAccent<对应色>}"
                             VerticalAlignment="Center" Margin="0,0,14,0" />
    <StackPanel>
      <TextBlock Text="<模块标题>" Style="{StaticResource MaterialDesignHeadline5TextBlock}" />
      <TextBlock Text="<模块副标题>" Opacity="0.55" Margin="0,2,0,0" />
    </StackPanel>
    <!-- 右侧操作按钮原样保留 -->
  </DockPanel>
</Border>
```
> 注意：`LinearGradientBrush` 的 `GradientStop Color` 需要 `Color` 而非 `Brush`；因此 `Theme.xaml` 同时再定义对应 `*Color` 资源（`<Color x:Key="BrushHeaderGradientStartColor">#F8FAFC</Color>` 等）。**不要**用 `{Binding}`，统一 `{DynamicResource}`。

- 如果 XAML 编译报 `LinearGradientBrush` 无法解析颜色键（你定义为 `<Color>` 而某些处仍用 `<SolidColorBrush>`），统一在 `Theme.xaml` 内**同时**定义 `*Color`（`<Color>`）与对应 `Brush*`（`<SolidColorBrush>`），命名规则 `BrushXxx` / `BrushXxxColor` 成对出现。
- 如果某处现有 `Card` 显式 `UniformCornerRadius="6"`，**不要**强行改成 12；保留显式值。
- 如果应用启动后某模块崩了 (`XamlParseException`)，立即回滚该模块的 XAML 改动并在 `docs\规划\视觉回滚.txt` 记录原因，**不要**为了 hack 而 catch 吞异常。
- 如果 `AppIcon.ico` 包含的最大分辨率 < 64x64，标记 `[待确认]` 不重生成；MetroWindow `Icon` 仍可用（自动按可用尺寸缩放）。
- 如果 Release 构建后 exe 增量超过 1.5 MB，立即砍掉**最大那个**插画（最常见是 `home-hero` `DrawingImage` 太复杂），简化几何后重测。
- 如果 `Resources\Illustrations.xaml` 单文件超过 1500 行，必须拆为按模块分文件（`HomeHero.xaml` 等），但**仍**通过 `Illustrations.xaml` 一处合并，避免 App.xaml 字典数量膨胀。

## 【示例】

**正例 1（导航图标加色）**：
```xml
<materialDesign:PackIcon Kind="LanConnect"
                         Width="22" Height="22"
                         Foreground="{DynamicResource BrushAccentBlue}"
                         Margin="0,0,14,0" VerticalAlignment="Center" />
<TextBlock Text="当前网络"
           Foreground="{DynamicResource BrushSidebarText}"
           VerticalAlignment="Center" FontSize="13" />
```

**反例 1**：
```xml
<materialDesign:PackIcon Kind="LanConnect" Foreground="{DynamicResource BrushAccentBlue}" />
<TextBlock Text="当前网络" Foreground="{TemplateBinding Foreground}" />
```
`TemplateBinding` 在 NavItemStyle 之外的 StackPanel 内不解析 → 字色失效。**禁止**。

**正例 2（卡片隐式样式）**：在 `Theme.xaml` 写一次 `<Style TargetType="materialDesign:Card">`，让 `MainWindow.xaml` 里 30 多张 Card 自动统一。

**反例 2**：在每张 Card 上都重复 `UniformCornerRadius="12"` —— 维护成本高，**禁止**。

**正例 3（Badge 使用）**：
```xml
<Border Style="{StaticResource BadgeSuccess}">
  <StackPanel Orientation="Horizontal">
    <materialDesign:PackIcon Kind="CheckCircleOutline" Width="12" Height="12" Margin="0,0,4,0" />
    <TextBlock Text="{Binding WgStatusText}" />
  </StackPanel>
</Border>
```
（即使 `WgStatusText` 字符串当前是乱码也照样接，文本内容由"乱码修复"brief 负责。）

**反例 3**：
直接给 TextBlock 加红色背景与圆角硬编码 `Background="#22C55E" Padding="10,3" CornerRadius=...` —— 没复用 `Theme.xaml`，**禁止**。

**正例 4（DrawingImage 几何插画）**：30–60 行 XAML，以 2 个椭圆 + 1 条 PathGeometry 表示"网络"主题。

**反例 4**：在 Illustrations.xaml 中用 500 行 PathGeometry 描绘一只猫 —— 体积爆炸 + 主题不符，**禁止**。

**正例 5（动效克制）**：导航 hover Opacity 0.85 → 1，150ms。

**反例 5**：导航 hover 用 `ScaleTransform 1 → 1.05` —— 文字会撕裂、像素抖动，**禁止**。
