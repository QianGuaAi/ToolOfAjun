# 启动基线说明 - Codex 档案复制

日期：2026-06-08

## 变更范围

- `MainViewModel` 构造函数新增 `CopyCodexProfileCommand` 命令对象创建与公开属性绑定。
- `MainModulesView.xaml` 的 Codex 配置面板新增局部紧凑按钮样式与“复制”按钮。
- 未在 `App.OnStartup`、`MainWindow` 构造函数或 `ScheduleStartupBackgroundLoads()` 中新增同步 IO、网络请求、WMI、注册表查询或后台批量任务。

## 启动影响判断

- 构造期新增内容仅为一个 `AsyncRelayParameterCommand` 对象和属性引用，属于启动期允许的命令对象创建。
- 复制动作的档案解密、DPAPI 重新加密、保存档案库均只在用户点击“复制”后执行，不在启动期执行。
- Codex 面板 XAML 仍由 `CodexProfilesDeferredTemplate` 按 `CurrentModule=CodexProfiles` 延迟挂载，不增加 Home 首屏模块渲染负担。

## 未实测原因

本次为窄范围 UI/命令变更，未启动桌面程序采集首帧计时；以 Release 构建作为基础验证。若后续同时调整 `App.OnStartup`、`MainWindow` 构造函数或 `MainViewModel` 启动加载调度，应重新采集首帧、稳态私有工作集和单 exe 体积。
