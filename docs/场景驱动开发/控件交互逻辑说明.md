# 控件交互逻辑说明

> 文档定位：本文是场景驱动开发范式自动生成并持续维护的用户界面事实说明书。它记录用户可见页面、弹框、控件、按钮、筛选项、表格列、提示文案、禁用状态、校验规则、跳转逻辑和权限展示。
> 本文件使用新项目推荐文件名；请按项目实际页面、弹框、控件和权限展示补齐界面事实。
> 本文只回答“用户看得见、点得到、会收到什么反馈”，不记录完整业务流程或实现状态。

## 一、维护规则

1. 用户输入 `开qg` 并确认执行后，若本轮新增、删除或编辑任何用户可见控件，必须同步维护本文。
2. 控件说明必须来自源码、运行界面、截图、测试或用户确认，禁止凭空补写不存在的控件。
3. 删除控件时，必须同步删除或标注对应说明，避免留下孤儿控件说明。
4. 控件权限、禁用状态、校验规则和跳转逻辑必须和真实代码行为一致。
5. 每次只修改相关页面或控件条目；除非用户明确要求重建模板，不得整文件重写。

## 二、格式规范

```text

X.X.X页面或弹框名
页面或弹框功能描述。
```

示例：

```text

1.1.1.2"查询"按钮，功能是按当前筛选条件刷新用户列表。
```

### 2. 截图工具

模块功能描述：提供全屏截图、区域录像和独立录音入口，并在录音期间显示实时状态。

2.1.1截图工具页顶部操作区

页面功能描述：截图工具页顶部展示模块标题、录音状态条和截图/录像/录音/剪贴板编辑按钮。

控件编号：2.1.1.1
控件名称：录音中状态条

### 3. 日程 / 排班

3.1排班模块

模块功能描述：维护月份排班版本、人员、每日总休目标和班次单元格。

3.1.1排班工具栏

页面功能描述：排班页顶部提供新建、保存、人员导入、排班 Excel 导入导出、清空和缩放等高频操作入口。

3.1.1.1"导入排班"控件类型为文本按钮，功能是导入排班 Excel 并替换当前表格内容。

控件编号：3.1.1.1
控件名称：导入排班
控件类型：文本按钮
所在页面或弹框：排班工具栏
可见条件：排班页可见时常驻显示，位置在"复制上月"和"导出"之间。
启用条件：始终可点击；没有当前排班时，导入文件名需包含可识别的 `YYYY-MM` 年月；已有当前排班时可使用当前年月兜底。
点击或输入行为：点击后弹出 `.xlsx` 文件选择框；若当前已有排班，会先提示导入将替换当前表格内容；导入成功后将 Excel 中的年月、每日总休、人员和班次载入表格，并询问是否立即保存为本地排班版本。
成功反馈：状态栏显示导入年月、版本名、人员数量和文件名；导入成功的表格进入可保存、可导出状态；若选择立即保存，保存成功后刷新左侧版本列表并显示保存路径。
失败反馈：文件结构缺失、日期列不连续、年月无法识别、总休非 0.5 步进或班次不在白名单时弹出错误提示，并在状态栏显示失败原因。
校验规则：A1 必须为"姓名"，A2 必须为"日期"，A4 必须为"总休"；B2 起必须是连续日期；班次支持"白 / 卡 / 副 / 感 / 大 / 小 / 休 / 公 / 产 / 午"，旧"夜 / 大夜"归一化为"大"，"产假"归一化为"产"；"午"虽不在弹出菜单中显示，仍允许导入并按 0.5 天休息统计；仅当日期后统计列表头为"上班"时，才按该列把导出时显示为空白的白班还原为"白"。
跳转逻辑：无跨页面跳转；导入成功后停留在当前排班页并重建表格。
权限边界：本地桌面功能，无角色权限；保存动作写入当前 Windows 用户的 `%LOCALAPPDATA%\MyTools\Schedules`。
关联接口或命令：`ScheduleViewModel.ImportExcelCommand`、`ScheduleExcelImporter.ImportAsync()`、`ScheduleService.SaveAsync()`。
关联业务场景：排班 Excel 导入
证据来源：`src/MyTools/Views/SchedulePage.xaml`、`src/MyTools/ViewModels/ScheduleViewModel.cs`、`src/MyTools/Services/ScheduleExcelImporter.cs`
待确认项：无。

3.1.1.2"导出"控件类型为文本按钮，功能是将当前排班表格内容导出为 Excel。

控件编号：3.1.1.2
控件名称：导出
控件类型：文本按钮
所在页面或弹框：排班工具栏
可见条件：排班页可见时常驻显示，位置在"导入排班"右侧。
启用条件：已加载当前排班版本；不要求先执行自动设置休息日，`GeneratedAt` 为空时也可点击。
点击或输入行为：点击后弹出 `.xlsx` 保存对话框，默认文件名按当前排班年月和版本名生成；用户确认保存路径后，按当前界面表格内容写入 Excel。
成功反馈：状态栏显示导出文件路径；弹窗提示导出成功并询问是否打开该文件。
失败反馈：保存路径无效、文件被占用或导出异常时弹出错误提示，并在状态栏显示失败原因。
校验规则：导出内容来自当前排班版本的年月、每日总休、人员和班次单元格；班次显示与界面一致，旧"夜 / 大夜"归一化为"大"，"白"在 Excel 中显示为空白；人员汇总列包含"上班 / 休息 / 连上 / 末休 / 可上"，"末休"统计当前月份内周六和周日休息天数，"可上"统计当前行空白单元格与已设置上班单元格的合计。
跳转逻辑：无跨页面跳转；用户选择打开文件时交由系统默认程序打开 `.xlsx`。
权限边界：本地桌面功能，无角色权限；只写入用户在保存对话框中选择的文件。
关联接口或命令：`ScheduleViewModel.ExportExcelCommand`、`ScheduleExcelExporter.ExportAsync()`。
关联业务场景：排班 Excel 导出
证据来源：`src/MyTools/Views/SchedulePage.xaml`、`src/MyTools/ViewModels/ScheduleViewModel.cs`、`src/MyTools/Services/ScheduleExcelExporter.cs`
待确认项：无。

3.1.2排班表格

页面功能描述：按月份日期展示姓名、星期、日期、实休、总休、人员班次格和行末汇总，支持点击单元格弹出班次菜单。

3.1.2.1"班次单元格"控件类型为表格单元格按钮，功能是展示并编辑某人员某日期的班次。

控件编号：3.1.2.1
控件名称：班次单元格
控件类型：表格单元格按钮
所在页面或弹框：排班表格
可见条件：排班版本已加载，且对应人员行位于当前滚动可视区域或缓冲区域内。
启用条件：排班版本已加载；人员行和日期列存在。
点击或输入行为：单击后当前格进入选区并弹出班次菜单，可选择"白 / 卡 / 副 / 感 / 大夜 / 小 / 休 / 公 / 产假 / 小1 / 清空"；菜单隐藏"午"，已有"午"数据仍可显示和统计；按住鼠标拖拽可选择矩形区域，`Shift` 点击按源格到目标格扩展矩形选区，`Ctrl` 点击追加或取消单格选择；选区存在时按 `Delete` 清空选中班次格。
成功反馈：单元格文字立即刷新；空白格显示"·"，"白"不显示文字，旧"夜"归一化显示为"大"，"产假"写入后显示为"产"；"大 / 小 / 副"使用白字深底，"休 / 卡 / 感 / 公 / 产 / 午"使用各自班次底色，其中"公"和"午"底色一致，"产"使用浅橙色；周末和其它节假日的空白格与"白"格使用蓝色列底色，已有专用班次色的格子不被节假日列底色覆盖；蓝色边框表示选中单元格，绿色边框表示填充源单元格；行末汇总显示"上班 / 休息 / 连上 / 末休 / 可上"，其中"末休"为当前月份周六和周日休息天数合计，"可上"为空白单元格与已设置上班单元格合计。
失败反馈：无独立失败反馈；保存、导出或自动生成失败由对应按钮流程提示。
校验规则：班次代码必须来自 `ShiftCodes` 支持的集合；界面刷新时按 `ShiftCodes.Normalize` 归一化旧"夜"；"产"计入 1 天休息，不计入上班和连续上班。
跳转逻辑：冲突侧栏点击定位时可滚动并高亮对应班次单元格。
权限边界：本地桌面功能，无角色权限；数据保存到当前用户本地排班目录。
关联接口或命令：`ScheduleViewModel.SetCell()`、`ScheduleViewModel.ApplySmallNight1()`、`ScheduleViewModel.FillCellsFromSource()`、`ScheduleViewModel.ClearCells()`、`SchedulePage.ResolveCellBg()`、`SchedulePage.ResolveCellFg()`。
关联业务场景：排班单元格编辑
证据来源：`src/MyTools/Views/SchedulePage.xaml.cs`、`src/MyTools/Services/ScheduleModels.cs`
待确认项：无。

3.1.2.2"填充"控件类型为工具栏按钮，功能是用源单元格班次批量填充当前选区。

控件编号：3.1.2.2
控件名称：填充
控件类型：工具栏按钮
所在页面或弹框：排班工具栏
可见条件：排班页面可见。
启用条件：按钮常驻可点击；无选区时点击会提示先选择单元格。

失败反馈：未选择单元格时弹出提示"请先在排班表中选择要填充的单元格。"；源坐标无效时弹出提示"请先选择一个源单元格。"。
校验规则：只接受排班表中有效的人员行和日期列；非空代码写入后标记为 `IsManual=true`，空白写入后标记为 `IsManual=false`。

权限边界：本地桌面功能，无角色权限；数据保存到当前用户本地排班目录。
关联接口或命令：`SchedulePage.FillSelectedCells_Click()`、`ScheduleViewModel.FillCellsFromSource()`。
关联业务场景：排班单元格批量编辑
