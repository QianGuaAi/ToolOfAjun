# MyTools 功能对标改进清单

> 目标：每个模块参照同类成熟软件的常见体验，按“先高频、再增强、最后专业化”的顺序持续完善。

## 1. 首页与导航

### 对标方向
- Windows 设置、PowerToys、HWiNFO：左侧稳定导航，首页展示关键状态和高频入口。

### 已落地
- 左侧导航紧凑化并增加滚动，避免功能增加后入口被挤出。
- 首页 Hero 和快捷入口压缩，减少装饰占位。
- 首页新增功能搜索区，可按“录像 / 导出 / 转换 / 排班”等关键词直接跳转模块。
- 首页新增最近使用区，记录最近打开的图片、音视频、转换输出和排班入口。

### 后续增强
- 每个模块增加统一的空态卡片：说明当前状态、主操作按钮、支持格式。
- 功能搜索后续可扩展为快捷键呼出和跨模块动作执行。

## 2. 截图、录像、录音

### 对标方向
- ShareX、Windows 截图工具、OBS：快速截图、区域录像、热键、录制状态明确、输出自动定位。

### 已落地
- 支持全屏/区域/当前窗口截图。
- 支持截图后编辑器、剪贴板、文件哈希。
- 支持截图历史：自动保存最近 20 张截图缩略图，可复制、编辑、打开、删除。
- 录像与录音使用 WASAPI Loopback 录系统声音，停止后自动定位文件。
- 录像开始前显示 3 秒倒计时，录制中在区域窗口显示录制时长。
- 支持 GIF 录制模式，适合短操作演示且不录制声音。
- 页面头部、快捷键卡片和行为卡片已压缩。
- 录制输出目录和录音输出目录在界面内可见，并可随时重新选择。
- 录像增加帧率和 MP4 画质预设，可在 15/30/60 FPS 与体积优先/均衡/高清之间切换。

### 后续增强
- 后续可增加录制快捷键与录制边框颜色设置。

## 3. 图片查看与简单编辑

### 对标方向
- IrfanView、XnView、Windows 照片：快速打开、轻量编辑、批量转换、低干扰信息栏。

### 已落地
- 支持图片打开、拖入、缩放、旋转、翻转、灰度、复制、另存、标注。
- 支持中心裁剪、亮度、对比度和锐化轻编辑；复制、另存、标注共用处理后的结果。
- 支持上一张/下一张，同目录图片浏览。
- 右侧信息栏压缩为 220 宽，预览区域更大。
- 批量改尺寸可通过“格式转换”模块完成，支持多选图片、设置最大宽高、质量和输出目录。

### 后续增强
- 增加“另存为 WebP”能力，需评估 Win7 兼容库。

## 4. 音视频播放

### 对标方向
- VLC、PotPlayer：多格式播放、进度/音量控制、外部播放器兜底、播放列表。

### 已落地
- “视频查看”统一为“音视频播放”。
- 支持打开视频和音频，支持播放/暂停、停止、进度、音量、静音、外部打开。
- 支持 `0.5x / 1x / 1.5x / 2x` 播放速度切换。
- 支持一次打开或拖入多个文件形成播放列表，播放结束后自动播放下一项；右侧列表支持双击切换、拖拽排序、搜索过滤、移除单项、复制清单、清理失效项、清空列表、收藏播放列表、保存为 `.m3u8`、载入 `.m3u/.m3u8` 和最近播放列表快捷入口。
- 支持播放模式：顺序、列表循环、单项循环、随机。
- 支持临时 A/B 片段循环和当前媒体书签点。
- 支持当前帧截取为 PNG，并自动进入图片查看继续浏览、复制、另存或轻编辑。
- 支持生成音频波形 PNG，并在播放器进度条上方紧凑展示；点击或拖拽波形可跳转到对应播放位置，播放时显示当前位置指示线；Shift+左拖或右键拖拽波形可设置 A/B 循环区间，选区两侧支持拖动微调，当前媒体可保存多个 A/B 区间并在右侧列表套用。
- 支持快捷键：空格播放暂停、左右键快退快进、上下键音量。
- 支持 `.srt` 外挂字幕选择；打开媒体时会自动载入同目录同名字幕，并在画面底部同步显示。
- 支持字幕时间偏移微调和字幕字号调整。
- 保存 `.m3u8/.m3u` 播放列表时，可把当前媒体保存的 A/B 区间写入 `#MYTOOLS-AB` 注释备注。
- 右侧媒体信息栏压缩为 220 宽。

## 5. 格式转换

### 对标方向
- HandBrake、IrfanView、FFmpeg 前端：预设、批量队列、输出路径可见、失败不中断。

### 已落地
- 图片转换与音视频转换双列紧凑布局。
- 图片和音视频均支持多选批量转换。
- 批量转换逐个执行，失败不中断后续文件。
- 支持批量队列表格：文件名、状态、输出路径、错误消息。
- 队列项支持打开输出位置、复制消息、重试、移除，转换空闲时可清空队列。
- 支持输出目录选择：同目录、桌面、指定目录。
- 支持预设：图片压缩、头像 512、视频转 MP4、音频转 MP3。
- 结果区汇总成功/失败数量，并提供“打开位置”。
- 转换中可取消，取消后停止后续队列并尝试结束正在运行的 FFmpeg。
- 转换队列支持拖拽排序、上移/下移排序；批量转换会按当前队列顺序执行。
- 转换中支持暂停/继续队列，暂停会在当前文件完成后阻止后续项继续执行。

## 6. 文件哈希校验

### 对标方向
- HashTab、7-Zip 校验、PowerShell Get-FileHash：多算法、复制方便、拖拽计算。

### 已落地
- MD5 / SHA-1 / SHA-256 / CRC32 单遍计算。
- 截图工具页和文件验证页共用结果格式。
- 支持点击结果复制。
- 支持粘贴官方校验值，自动识别 CRC32 / MD5 / SHA-1 / SHA-256 并判断匹配状态。
- 支持批量文件哈希表格。
- 支持导出校验清单 `.txt`。
- 支持批量结果按 MD5 / SHA-1 / SHA-256 / CRC32 一键复制。
- 支持导入 MyTools 或常见格式校验清单，并对批量结果标注匹配、不匹配或未找到。

## 7. SQL 导出与查询

### 对标方向
- SSMS、DBeaver、DataGrip：连接历史、表搜索、查询结果导出、长任务进度。

### 已落地
- 支持 SQL Server / PostgreSQL / MySQL。
- 支持连接历史和 DPAPI 密码保护。
- 支持最近连接快速卡片，一键回填服务器、端口、用户名和密码。
- 支持表导出 Excel、查询结果导出。
- 查询结果支持导出 CSV，适合轻量交换和大数据量后续处理。
- 查询结果支持复制选中单元格/行；未选择时复制全部结果。
- 导出过程显示当前阶段、已处理行数、耗时和输出文件大小，完成后在提示中汇总行数、耗时、大小与路径。
- SQL Server 表导出支持取消；导出中可中断当前任务。
- SQL Server 大表超过单个 Excel 工作表上限时，会在同一 `.xlsx` 内自动拆分为多个 Sheet。

## 8. 排班管理

### 对标方向
- Excel 排班表、排班 SaaS：表格紧凑、规则校验、导出稳定、冲突提示。

### 已落地
- 排班表紧凑化，支持版本、人员、自动休息、Excel 导出。
- 导出 Excel 修复 OpenXML 顺序，表头保持星期、日期、总休三行结构。
- “午”按 0.5 天休息统计，界面和 Excel 一致。
- 支持排班冲突侧栏：连续上班超限、人员休息不足、每日需休不匹配。
- 支持人员模板导入/导出 CSV。
- 支持复制上月人员与复制某人整月班次。
- 班次颜色图例固定显示在底部。
- 右侧冲突列表支持定位按钮，可按冲突项高亮对应人员/日期单元格。
- 右侧新增周休均衡统计，展示每周休息总量、人均休息和人员差值。
- 编辑模式切换会刷新动态表格，避免标题显示“编辑中”但格子、姓名和需休人数仍保持只读。
- 表格支持缩放按钮和 `Ctrl + 鼠标滚轮` 缩放。
- 第 3 行保留为每日总休目标；实际休息必须精确等于该目标，少休和多休都会进入冲突侧栏并阻止保存。
- 自动设置休息日会继续校验每日精确人数和连续上班不超过 5 天，无法满足时在状态栏与冲突侧栏提示。

## 9. 系统信息、性能测试、传感器

### 对标方向
- 任务管理器、HWiNFO、CPU-Z：状态一屏可扫、刷新可控、异常提示明确。

### 已落地
- 系统概览、硬件信息、传感器入口、性能测试。
- 性能测试结果支持复制到剪贴板和导出 `.txt`。
- 传感器支持手动、2 秒、5 秒刷新模式，并提供单次刷新按钮。
- 传感器状态栏会提示温度或负载异常，便于快速发现高温或高负载。
- 首页展示 CPU/内存/磁盘关键状态的小型摘要。
- 首页结合传感器数据提示温度/负载风险，未启用或读取失败时给出明确状态。

### 后续增强
- 首页温度风险后续可扩展为按 CPU/GPU 分组的迷你曲线。

## 10. 启动项与程序卸载

### 对标方向
- Autoruns、Windows 启动应用、BCUninstaller：列表密度高、搜索过滤、风险操作确认。

### 已落地
- 支持启动项查看与启停。
- 支持程序卸载列表加载和卸载。
- 启动项展示发布者和识别出的可执行路径，并支持按名称、发布者、路径、命令和位置搜索。
- 启动项显示文件存在性，可按“文件存在 / 文件不存在 / 未识别路径”搜索。
- 启动项显示数字签名状态，可按“已签名 / 未签名 / 未检测签名”和证书主体搜索。
- 卸载列表支持按程序名、发布者、版本、路径和来源搜索。
- 卸载列表支持按名称、安装日期、大小、发布者排序，并支持大小/安装时间过滤。
- 卸载列表支持勾选当前筛选结果、清除选择，并导出已选择或当前筛选程序清单。
- 卸载前确认框显示发布者、版本、安装路径、来源、权限提示和完整卸载命令。
- 卸载列表增加批量静默卸载候选检测，但默认不自动批量执行卸载。
- 启动项增加签名证书链可信状态校验。
- 启动项增加来源分类，区分注册表 Run 与 MyTools 禁用备份，并显示当前用户/所有用户范围。

### 后续增强
- 启动项后续增加任务计划程序、启动文件夹、服务项扫描。

## 11. 系统优化、垃圾清理、微信清理/备份

### 对标方向
- Windows 存储感知、BleachBit、CCleaner：先扫描、再确认、可回退、清理项透明。

### 已落地
- 自动优化、垃圾扫描/清理、微信清理/备份/恢复。
- 运行期日志与确认弹窗。
- 所有清理项增加“大小 / 风险 / 建议”三列。
- 增加清理前导出报告。
- 增加白名单目录，避免误删。
- 微信备份增加最近备份记录与快速恢复入口。
- 微信恢复增加按类别选择恢复，可只恢复文字、图像、视频、语音、文件或缓存中的一部分。

### 后续增强
- 微信备份增加备份包校验与损坏文件定位。

## 12. WireGuard

### 对标方向
- WireGuard 官方客户端：隧道状态清晰、配置导入、连接日志可追踪。

### 已落地
- 支持配置生成、连接/断开、网卡状态判断。
- 支持导入 WireGuard `.conf` 配置文件。
- 增加连接日志查看按钮。
- 增加连接耗时和最近连接时间。
- 增加多个隧道配置列表。
- 隧道列表增加加载、重命名和删除入口，便于管理本地 `.conf` 配置。
- 隧道列表增加差异预览和导出入口，可比较当前编辑区与保存文件并另存单个 `.conf`。

### 后续增强
- 增加隧道配置内容敏感字段脱敏预览。

## 13. Codex 配置管理

### 对标方向
- 配置管理器、IDE Profile：导入、切换、备份、差异对比。

### 已落地
- 支持 Codex 配置导入、导出、应用、编辑。
- 增加配置差异预览，可比对当前 `%USERPROFILE%\.codex` 与记录内容。
- 增加配置标签和备注，便于按账号、代理、模型用途归类。
- 增加最近应用时间记录，并按最近使用优先排序。
- 增加配置导入时的敏感字段脱敏摘要，导入前展示常用配置键和 auth.json 字段结构。

### 后续增强
- 增加配置导入后的快速复制脱敏摘要。

## 14. 系统设置与备份迁移

### 对标方向
- Windows 备份、应用迁移工具：导入导出清晰、风险提示、关联设置易重做。

### 已落地
- 系统设置页改为导出备份、导入恢复、音视频关联三块操作面板。
- 支持备份设置、历史、排班、节假日、Codex 配置、WireGuard 配置、FFmpeg 依赖。
- 增加备份预检：列出将导出的文件数量、大小和缺失项。
- 增加导入前差异摘要：显示来源机器/用户、备份文件数、预计覆盖和新增数量。
- 增加“只恢复某类数据”选择，支持按设置历史、排班本地数据、Codex、WireGuard、FFmpeg 分区恢复。
- 增加备份包校验按钮，新备份会在 manifest 记录文件清单和大小，可检查缺失或大小不一致。

### 后续增强
- 增加备份包压缩为单 ZIP 的可选模式。

## 15. 安装与文件关联

### 对标方向
- VLC、7-Zip 安装器：安装时可选关联，安装后可重新关联，卸载时清理干净。

### 已落地
- 安装器支持音视频关联选择和静默 `/associate-media`。
- 程序内可重新关联所有音视频。
- 卸载器清理 MyTools 写入的关联。
- 增加关联状态检测，系统设置页显示视频/音频当前默认打开数量和打开方式注册数量。
- 增加只关联视频、只关联音频和关联全部按钮；静默安装增加 `/associate-video`、`/associate-audio`。
- 增加恢复系统默认关联入口，会移除当前用户下 MyTools 写入的音视频关联并提示 Windows 默认应用行为。
- 增加一键打开 Windows 默认应用设置页。

### 后续增强
- 增加文件关联变更后的资源管理器图标刷新说明弹窗精简版。
